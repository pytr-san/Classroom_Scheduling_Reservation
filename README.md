Classroom Scheduling System
ACCESS Department

Overview

    The Classroom Scheduling System is a web-based application developed to manage classroom schedules for daily classes and examination periods. 
    The system automates scheduling processes, helps prevent time and room conflicts, and provides real-time access to classroom availability, 
    ensuring an organized academic schedule for students, instructors, and administrators.This project focuses on efficient schedule management 
    rather than reservations and is designed to meet the operational needs of the ACCESS Department.


The system supports multiple user roles with the following capabilities:

Students and Instructors

    Register and log in to the system
    
    View assigned class and examination schedules
    
    Enroll in available courses

Administrators

    Create, edit, and manage classroom schedules
    
    Assign schedules to courses
    
    Manage course information, including subjects and instructors
    
    Save and upload finalized schedules
    
Features

    Automated classroom scheduling
    
    Conflict detection for rooms and time slots
    
    Role-based access control
    
    Course and subject management
    
    User-friendly interface

Technologies Used

    Frontend: React, Vite, JavaScript, HTML, CSS
    
    Backend: Node.js, Express
    
    Database: MySQL
    
    Authentication: JWT-based authentication
